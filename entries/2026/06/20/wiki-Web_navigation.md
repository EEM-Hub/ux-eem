## Web Navigation: Types, Styles, and Design Principles

Web navigation is the process of traversing information resources on the World Wide Web, organized as hypertext or hypermedia, using a web browser. This topic covers the navigational structures that enable users to move through websites efficiently, including the taxonomy of navigation types (hierarchical, global, local), common UI patterns (navigation bars, sitemaps, dropdown and flyout menus), and the design challenges of building effective navigation systems. It is foundational to web usability and information architecture.

## Key Concepts

- **Web navigation** = traversing a network of web resources organized as hypertext/hypermedia; the tool used is the web browser.
- A website's overall navigation scheme comprises **four pieces**: global, local, supplemental, and contextual navigation.
- **Hierarchical navigation** is the primary system — structured general-to-specific — but is often perceived as restricting and needs supplemental systems.
- **Global navigation** shows top-level sections/pages and is present on every page.
- **Local navigation** consists of in-text links within a page that connect to other pages in the same site.
- Navigation design is highly variable — no universal guidelines exist; it depends on **information architecture** (the model/concept of how information is organized).
- Content may vary between logged-in and logged-out states, adding complexity to navigation design.
- Navigation is analogous to a road map — it lets visitors explore and discover areas of a website.

## Commands and Syntax

No commands or configuration syntax — this is a conceptual/design topic. However, the following HTML/UI patterns are referenced:

- **Navigation bar**: A dedicated section of a page for site-wide links.
- **Sitemap**: A hierarchical page listing all pages, also used as an XML document for web crawlers.
- **Dropdown menu**: A GUI control that reveals a list of options on click.
- **Flyout menu**: A menu that appears on hover or click, expanding to the side or downward.
- **Named anchor** (`<a>` element): Anchors a URL to text, creating a clickable hyperlink.

## Relationships

- **Information Architecture** — navigation design is an expression of IA; good IA yields good navigation.
- **Usability** — maximizing usability is the central goal of navigation design.
- **Web Design** — navigation is a core component of overall web design practice.
- **Human-Computer Interaction (HCI)** — navigation is an interaction technique studied within HCI.
- **Hypertext / Hypermedia** — the underlying structural model that makes web navigation possible (linked resources).
- **Responsive/Multi-device Design** — navigation must work across computers, tablets, and smartphones.
- **Web Crawlers / SEO** — sitemaps serve both users and crawlers, bridging navigation and discoverability.

## Exam-Relevant Points

- The four navigation components: **global, local, supplemental, contextual** — know the distinction.
- **Hierarchical navigation** is the primary system but is insufficient alone; it needs supplementary navigation.
- **Global navigation** appears on every page; **local navigation** is links within page text to other pages in the same section.
- A **sitemap** serves dual purposes: user navigation aid and crawler accessibility document.
- Tim Berners-Lee invented the World Wide Web in **1989**, which introduced web navigation.
- There are **no universal guidelines** for navigation design — it depends on information architecture and the specific site's content structure.
- Navigation must account for **different user states** (logged-in vs. logged-out) and **multi-level architecture**.
- The distinction between navigation **types** (hierarchical, global, local) and navigation **styles** (navbar, dropdown, flyout, sitemap, anchor) is important — types describe structural roles, styles describe UI patterns.
